## Что умеет

| | |
|---|---|
| 📓 **Настоящие тетради** | Обложки из кожи, ткани или крафта, корешок, резинка, ленточка-закладка. Обложка открывается анимацией, страницы листаются со сгибом листа. |
| ✒️ **Перья** | Шариковая ручка, перьевая ручка с каллиграфическим нажимом, карандаш с текстурой зерна и штриховкой наклоном, маркер-выделитель. |
| 🎨 **Палитра** | Любимые цвета на панели, полный выбор цвета (HSV, HEX), готовые наборы и недавние цвета. |
| 🧽 **Ластик и лассо** | Стирание штрихом целиком или областью, временный ластик кнопкой пера. Лассо: выделить, перенести, масштабировать, перекрасить, дублировать. |
| 🖼️ **Картинки в записях** | Вставка из буфера, галереи, камеры, перетаскиванием из другого приложения или через «Поделиться». Картинку можно двигать, масштабировать и закрепить, чтобы писать поверх. |
| 📅 **Дневник** | Каждая страница с датой, новый день — новая страница. |
| ✋ **Под планшет и стилус** | Нажим, наклон, наведение пера, отклонение ладони, масштаб двумя пальцами, отмена касанием двух пальцев, повтор — трёх. |
| 📄 **Любой лист** | A4, A5, A6, B5, Letter или «по экрану», портрет или ландшафт; чистая бумага, линейка, клетка, точки, нотный стан. |
| 💾 **Только на устройстве** | Автосохранение каждого штриха, экспорт тетради в PDF и страницы в PNG. |

Разрабатывается и проверяется на **POCO Pad X1** со стилусом **POCO Focus Pen**, но работает на любом Android-планшете (и телефоне) с Android 10 и новее.

## Скачать

Готовый APK лежит в разделе [Releases](../../releases/latest). Скачай файл `NoteCreate-v….apk` на планшет и установи (Android попросит разрешить установку из этого источника).

## Сборка из исходников

Нужны JDK 17 и Android SDK (проще всего — [Android Studio](https://developer.android.com/studio)).

```bash
git clone https://github.com/PandorTools/NoteCreate.git
cd NoteCreate
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Каждый push в `main` собирает APK в GitHub Actions (вкладка **Actions → артефакт NoteCreate-apk**). Тег вида `v0.1.0` публикует релиз с APK автоматически.

## Устройство проекта

```
app/src/main/java/com/pandortools/notecreate/
├── data/        модель, локальное хранилище тетрадей, настройки
├── ink/         движок рукописи: PageView (ввод стилуса), PageRenderer, PageCurl, геометрия
└── ui/          Jetpack Compose: библиотека, редактор, палитра, обзор страниц, настройки
```

Kotlin · Jetpack Compose · Material 3 · свой движок отрисовки на Canvas с минимальной задержкой.
