## Возможности

| | Что можно делать |
|---|---|
| 📓 **Свои тетради** | Выбирать обложку, материал и цвет. Быстро возвращаться к последней открытой тетради. |
| ✍️ **Естественное письмо** | Писать перьевой ручкой, шариковой ручкой, карандашом и маркером с поддержкой нажима и наклона стилуса. |
| 🛡️ **Защита от ладони** | Случайное касание ладонью не должно мешать письму. Для рисования используется стилус. |
| 🧽 **Точный ластик** | По умолчанию стирает только участок под кончиком. При необходимости можно переключиться на удаление целого штриха. |
| 🪢 **Лассо** | Выделять рукописные штрихи и картинки, перемещать, менять размер, перекрашивать и дублировать. |
| 📄 **Листы под задачу** | A4, A5, A6, B5, Letter, открытка, широкий лист или собственный размер в миллиметрах. Книжная и альбомная ориентация. |
| 📐 **Разметка и цвет бумаги** | Чистый лист, линейка, широкая линейка, клетка, точки или нотный стан; светлая, кремовая, серая и тёмная бумага. |
| 🤏 **Жесты** | Щипок двумя пальцами масштабирует и перемещает лист. Свайп от края перелистывает страницу. Действие касания тремя пальцами можно настроить. |
| 🖼️ **Картинки на странице** | Добавлять изображения из галереи, камеры и буфера обмена, перемещать их и закреплять под рукописью. |
| 📚 **Обзор страниц** | Находить нужный лист по миниатюре, добавлять и дублировать страницы, менять порядок и продолжать с текущей. |
| 📤 **Экспорт** | Сохранять тетрадь в PDF, отдельную страницу — в PNG. Данные хранятся локально. |

## Скачать и установить

Открой [последний релиз](../../releases/latest) и скачай APK на Android-устройство. При первой установке Android может попросить разрешить установку приложений из выбранного источника.

Минимальная версия — **Android 10**. Приложение рассчитано на работу со стилусом, но поддерживает и обычное сенсорное управление.

## Что нового в 0.1.3

- Фигуры автоматически выравниваются после удержания пера: линии, круги, треугольники и прямоугольники. Добавлены линейка, слои, текстовые блоки и новые кисти.
- Исправлено отображение панели инструментов на планшетах средней ширины.
- Добавлены шаблоны страниц, закладки и подборка записей «В этот день».
- PDF импортируется отдельными страницами, сканер выравнивает бумагу, а поверх можно писать стилусом.
- Поиск распознаёт русский почерк на устройстве после однократной загрузки модели.
- Тетради экспортируются и восстанавливаются из архива `.ncbook`.
- Виджет «Сегодня» открывает заметки одним нажатием.
- Обновлены библиотека, палитра, первый запуск и настройки приложения.
- APK 0.1.3 подписан тем же ключом, что и 0.1.2; GitHub Actions собирает и публикует APK при создании версии.

Подробный список изменений — в [CHANGELOG.md](CHANGELOG.md).

## Сборка

Нужны JDK 17 и Android SDK. Открой проект в [Android Studio](https://developer.android.com/studio) или выполни команды:

```bash
git clone https://github.com/PandorTools/NoteCreate.git
cd NoteCreate
./gradlew assembleDebug
```

Установочный файл для локальной сборки появится здесь:

```text
app/build/outputs/apk/debug/app-debug.apk
```

Каждый push в `main` запускает проверочную сборку в GitHub Actions. Установочные APK релизов подписываются стабильным ключом; скачивай их из раздела Releases, а CI-артефакты используй для проверки сборки.

## Технологии

Kotlin · Jetpack Compose · Material 3 · Android Canvas

```text
app/src/main/java/com/pandortools/notecreate/
├── data/  модели, локальное хранение тетрадей и настройки
├── ink/   рукописный ввод, рендеринг, жесты и перелистывание
└── ui/    библиотека, редактор, страницы и настройки
```
